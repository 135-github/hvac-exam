## 学习记录

记录只存于当前浏览器，不会上传 GitHub，也不会同步到其他设备。

- 原 GitHub 版本的 hvac-study-v1 数据会在第一次打开新版时转换为 hvac-memory-v2，保留对应客观题的练习次数、答对次数、错题、收藏与练习位置；判断题 A/B 会转换为 √/×。
- 转换不删除旧数据。旧模拟考试历史不纳入新版复习统计，可在“学习记录”中导出原站旧记录。
- 已有新版记录时不会重复转换或覆盖。
- 从 chatgpt.site 迁移：先在旧网址点击“学习记录 → 导出记录”，再在此站选择“导入记录”。不同域名不能自动读取彼此的浏览器数据。

## 开发检查

网站使用原生 HTML、CSS 和 JavaScript，无运行时外部依赖。

运行 `node tests/check-data.cjs` 检查两套数据的一致性、题号稳定性及原题与答案的指纹。它不需要安装依赖。

浏览器回归脚本为 `node tests/browser.cjs`，需要开发环境已安装 Playwright 及 Chromium。脚本会启动临时本地服务，验证全部客观题判分、手机布局、个人助记、续练和备份导入。可用 `BROWSER_CHANNEL=msedge` 选择已安装的 Edge；`PLAYWRIGHT_MODULE` 可指定已有 Playwright 模块路径。这些工具仅用于开发检查，访问网站无需安装。


## 建筑电气施工技术

- 独立入口：`construction/`，浏览器记录键 `construction-memory-v1`。
- 默认范围：教材红线、五角星及红色旁注＋2026-11-16新增7张手写资料。69道选择题、15张重点卡；25条参考或合并归档。新增15题，6张重复总结卡移入归档并关联旧笔记。教材页码未知的显示新资料页序；冲突留对照说明。
- 吕丽荣等《建筑电气施工技术》为用户指定教材；尚无P10、P74原文，不声称逐字覆盖。
- 考试：2026-11-17 08:30—10:30（中国标准时间）；电工高级工：2026-11-21，具体时段未提供。
- 原通风空调和电工题目、答案及存储键保持不变。
- `construction/review.txt` 可下载离线阅读；网页支持卡片回忆、自评复习、个人助记、笔记、收藏、导入导出。
- 内容重点区分：控制电缆普通支架≤2层；灯具>10kg固定悬吊装置5倍载荷≥15min；案例缺少保温、额定电压等条件时不做无条件判定。
- 每题在作答前显示 `pageRef`；遮挡页码标“页码待核”及照片定位。`examFocus` 区分考试重点与参考资料，`referencePoints` 存放移出的补充内容。所有默认入口、随机抽题、限时建议与统计均使用考试范围；旧练习和显式参考入口仍可访问旧内容。
- 修订题目的 `revision` 用于重新开放旧作答，避免旧答案判定套用新选项；旧响应保存在 `previousResponse`，个人笔记、草稿和学习记录保留。
- `node tests/construction.cjs` 验证题卡、移动端布局、考试时间边界、草稿续学和学科隔离；`node tests/marked-focus.cjs` 验证默认考试范围、页码、参考区、修订迁移和打印提纲；`node tests/instant-answer.cjs` 验证三个学科点选判题与自动前进。共用Playwright环境设置。


## 碎片时间、分步案例和离线（2026-11-14）

- 首页“手头还有几分钟？”按3/10/30分钟估算选题；以题型估算耗时，优先到期和薄弱内容，不计时、不催促。另开一轮仍保留原练习。
- 建筑电气13张案例卡支持找问题、写做法、说理由三步草稿和逐步核对，仍可直接看完整答案。草稿随原学习记录备份导出。
- `review/` 提供每科三页速记，可打印或存为PDF；条目链接回稳定原题号。精选不代替完整题库。
- `study-extras.js/css` 为共享可选工具，三科原答案和存储键不变。
- Service worker缓存23个必要静态资源，包括三科与速记页。初次成功缓存后离线可用；外部资料不缓存。更新完整缓存成功后等待，用户点“学习记录→保存并加载新版”才激活，不自动打断练习。
- 更新静态资源时同步提升`sw.js`的CACHE版本及首页资源版本；新文件需加入FILES清单。缓存失败不激活不完整版本。学习记录使用localStorage，缓存清理不清理记录。
- Web实现参考：[MDN Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)、[Cache.addAll](https://developer.mozilla.org/en-US/docs/Web/API/Cache/addAll)。
- `node tests/study-extras.cjs` 实测碎片时间选题、13×3步案例与草稿、速记返回原题、真正断网下三科切换，以及缓存失败重试和新版等待激活。使用与其他浏览器测试相同的Playwright环境变量。
